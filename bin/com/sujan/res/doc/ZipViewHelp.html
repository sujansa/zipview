Introduction

What is ZipView?
ZipView is ZIP Archiver software with which you can create Zip archives, extract files from an existing archive, view images and HTML files in an archive without creating temporary files.

What is special about ZipView?

ZipView is a platform independent software which can be run on any operating system which has Java Runtime Environment 6 installed on it.

With ZipView you can view HTML and image files* without extracting files.

System Requirements

Requires Java Runtime Environment 6 (JRE 1.6) or higher version which you can download from java.sun.com

Minimum**
  • 1.2 GHz Intel Pentium 4 processor, equivalent or higher
  • 256 MB of RAM (1GB on Windows Vista or later)
  • 52 MB available disk space
  • Java Runtime Environment 6 (JRE 6) or higher version

Installation

Just use it
This version of ZipView needs no installation.

Using ZipView

Creating Zip file

  • Click on the File menu and select New Zip Archive.
  • Now browse with the displayed file chooser and select a directory/folder which you want to compress.
  • Select a location to store the new Zip file and enter the name for the new Zip file.
  • Click Create

Opening a Zip file

  • Click on the File menu and select Open.
  • Now browse with the displayed file chooser and select Zip file.
  • Click Open.
  • The browser area displays the list of files in the Zip archive.

Known Issues

Java Runtime failure
Bugs in Java Runtime may cause the Java Runtime to exit, terminating the application without notice. You may submit such bug reports at java.sun.com
